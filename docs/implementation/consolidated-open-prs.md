# Объединение открытых PR #99, #100, #102, #103 и #104

Общая ветка предназначена для одного PR в `main`. Старые PR заменяются только
после подтверждённого создания общего PR; ветки не удаляются.

## Состав

| Исходный PR | Включённые изменения |
| --- | --- |
| #99 | Маскирование секретов в диагностических исключениях, crash-метаданных, Logcat и экспорте/буфере обмена; тесты редактирования диагностики |
| #100 | Постоянная область субтитров 104/120 dp, сохраняющая положение сферы |
| #102 | Жизненный цикл субтитров, облачка и состояния сферы с подтверждённым подключением |
| #103 | Подтверждение расходов, доходов, долгов, погашений и переводов; выбор денежных счетов; журнал защиты повторной записи; миграция Room 6 → 7 |
| #104 | Совместимые с Android ICU границы слов, обработка отмены корутин и ошибок подготовки операции |

Цепочка Live уже содержала изменения #102–104. Пересечение с #100 разрешено в пользу
`DavidLiveSpeechOverlay`, который включает требуемую постоянную область, роли
собеседников и анимации. Старый статический блок не добавляется вторым облачком.
Регрессионные проверки геометрии сферы входят в набор Live.

История #99 не имеет общего предка с текущей `main`. Из неё перенесён только
целевой коммит `412e244`, меняющий три файла диагностики и её тесты; старые версии
финансового репозитория и Room/DAO не переносятся. Это сохраняет актуальные
исправления целостности бюджета.

Общая удалённая ветка создаётся от актуальной `main` и получает итоговые файлы одним
коммитом. Для её слияния не нужны промежуточные PR или объединение несвязанных историй.

## Проверка в приложении

1. Обновить debug-сборку с сохранением данных; проверить загрузку существующего бюджета.
2. Открыть Live: первая фраза не должна приводить к падению ICU. Проверить подключение,
   переподключение, завершение ответа и исчезновение субтитров без смещения сферы.
3. Проверить предложения дохода/расхода, оба направления долгов, погашение и перевод.
   До подтверждения записей нет; повторное подтверждение не изменяет сумму повторно.
4. Проверить выбор разных счетов, неверную дату, переплату по долгу и смену профиля.
5. Проверить маскирование тестового секрета в диагностике и копируемом отчёте.

Реальное устройство, голосовой Gemini-сеанс и инструментальные Android-тесты
потребуют отдельного запуска. Автоматическое слияние общего PR в main не выполняется.
